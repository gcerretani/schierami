# Ask when the answer can change the decision

## Decision test

1. Look for the answer in accessible context, files and authorized sources first.
2. Consider plausible values of the missing fact. Could they change legality, starters, module, bench insurance, captain, objective or the stated confidence?
3. If yes, obtain it. Research public sporting facts; ask the user about private settings, identity, intended contest or preferences unavailable elsewhere.
4. If no, proceed without an unnecessary question. Revisit only if the decision changes. Do not invent numerical value-of-information calculations.

Distinguish a rule unknown (which scoring function?) from a forecast unknown (what will happen?). More player statistics cannot resolve an unknown scoring rule. Do not ask the user to predict whether the coach will start a player.

## Ask compactly and explain the impact

Ask one focused question, or a small group that the same screenshot can answer.

Examples:

- "Il modificatore include il portiere e quali soglie usa? Questo puo cambiare la scelta tra quarto difensore e quarto centrocampista."
- "Usate Basic, Easy o Master? Cambia l'ordine corretto della panchina Mantra."
- "La giornata 4 e quella della lega o del campionato reale? I file indicano numerazioni diverse."
- "Ci sono bonus/malus o regole di cambio personalizzati rispetto al regolamento che hai indicato?"

Never ask again for a known rule merely because a template has an empty field. Do not make users paste an entire regulation when one setting is enough.

## Graceful continuation

If the answer is unavailable, the user declines questions, or the deadline is near, state the unresolved rule, recommend invariant choices, and give a small set of conditional alternatives with explicit assumptions. Under severe time pressure prioritize eligibility, locks, no-vote exposure and the largest decision changes. Do not disguise a conditional lineup as an optimized final answer.

Examples: with modifier formula unknown, identify the secure core and explain which defender/midfielder comparison remains open. For an obscure competition, use supplied team news and say which starters cannot be independently verified. For unfamiliar custom rules, paraphrase them and test a small hypothetical case; ask only where ambiguity changes the outcome. Continue useful work in all cases.

## Stop asking

Stop when plausible answers would no longer change the recommendation, or when remaining uncertainty is explicitly represented by conditional advice. This is not permission to ignore a possible custom rule before any intake check.
