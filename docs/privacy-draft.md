# Privacy policy draft

This document is a draft for the initial skills-only release of Schierami and is not yet the public privacy policy URL for submission.

The initial skills-only plugin does not operate its own backend service and does not provide a Schierami account system. The Skill instructs ChatGPT to use information supplied by the user, connected tools the user has authorized, and current public web sources when needed for fantasy-football analysis.

Before publication, this policy must be reviewed against the final product behavior, hosting setup, analytics, support workflow, and any future Schierami MCP service.
