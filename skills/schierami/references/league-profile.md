# League profile handling

Never assume a public user's league settings.

Before making a recommendation that materially depends on league rules, obtain the relevant context from one of these sources, in order:

1. Connected league tools, when available.
2. Rules or screenshots supplied in the current conversation.
3. A direct user statement about the league.

Relevant settings can include:

- number of teams;
- auction budget and base price;
- allowed formations;
- defensive modifier and exact formula;
- substitutions and bench size;
- scoring bonuses and penalties;
- lineup deadline;
- roster constraints.

If a setting is unknown and does not materially affect the recommendation, proceed without blocking and state the assumption only when useful. If it could flip the recommendation, make the uncertainty explicit rather than inventing a default.
